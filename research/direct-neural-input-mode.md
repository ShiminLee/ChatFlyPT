# 直灌模式设计：把话变成神经输入（独立实验，不是聊天）

本文件只描述**设计**。该模式在代码上已经存在一半（受体目录 + 事件编码 + 独立实验面板），但**不属于正常聊天**，也不得与聊天会话共享状态。

## 1. 定位与红线

- 契约允许"明确标注、独立于聊天会话"的直接神经干预实验；禁止把它接回聊天，禁止把用户文本直接编码成神经磁带（旧的 `app.receive`/`INPUT_ALIASES` 已删除，见 `research/chatflypt-contract.md`）。
- 直灌模式的输出**不是对话**：它显示的是"向某群细胞注入了什么 + 盲读出的内部活动"，不显示"果蝇听懂了这句话"。

## 2. 哪里接受（输入落点）

输入落点必须是**有来源的受体群体**，不能是任意细胞集合。现有可用层次：

| 层次 | 例子 | 证据来源 | 备注 |
|---|---|---|---|
| 通道 + 侧别 | `mc_cva:left`、`foreleg_touch:right` | MaleCNS 注释（`class`/`type`/`subclass` + `rootSide`） | 正常环境通路用的就是这一层 |
| 通道 + 部位子集 | `leg_sweet_local` 的前/中/后腿 × 左右 | `body_part_ids`，来自跗节接触的真实腿别 | 未核实部位会明确报"无该部位映射" |
| 高级/未映射群 | `advanced_*`、hook、campaniform | 目录审计 | 只作对照，不冒充已验证入口 |

原则：**宁可拒绝也不猜**。请求不存在的侧别/部位时，实验明确失败，不换另一侧代替。

## 3. 怎么输入（编码）

沿用现有 `sensory_events.encode_inputs` 的三种工程包络：

- `tonic`：恒定率（默认 100 Hz）
- `touch_transient`：峰值 150 Hz + 15 ms 指数衰减（触碰类）
- `pulse_envelope`：36 ms 脉冲间隔、5 ms 门宽（鸣声类）

参数一律标为工程设定：**不是频率代码、不是浓度、不是声压**。事件以 0.1 ms 步长、固定种子生成，可重放。

## 4. 码本问题（必须先说清）

一句话没有唯一的神经编码。"把'向左'编码成某群细胞的 100 Hz"是**我们定义的码本**。历史工程码本（听感觉细胞 `left/right/forward/stop`）曾被外部读出器 37/37 识别，但那证明的是"码本可读"，不是"果蝇理解了方向"。因此：

- 任何直灌实验必须**同时记录码本定义**（哪个词→哪些细胞→什么时序），并声明它是约定而非生物编码；
- 读出端必须走同一套盲读出（排除感觉细胞与直接输入细胞），否则"读出"只是把输入抄回来；
- 不允许把"读出=码本原词"包装成"果蝇回应了这句话"。

## 5. 与聊天的隔离

- 独立的 HTTP 入口与独立的实验面板（现有 `/api/stimulate`、`/api/observe`）；聊天入口 `/api/converse` 在 `input_mode='environment_only'` 下**拒绝**任何直接神经输入。
- 独立状态：直灌实验会话不共享聊天的神经/身体会话（旧连接组实验亦不得与 MaleCNS 合并为同一个体）。
- 记录分开保存（`reports/general-sensory/interactive/`），不与 `reports/dialogue/` 混放。
- UI 明示"实验性直接神经干预，不代表环境自然感知"。

## 6. 验收标准（若今后启用）

1. 每个实验记录包含：码本定义、实际投递细胞 ID 与事件时序、盲读出结果、以及"这不是对话"的显式标注。
2. 阴性对照：静默输入必须不产生标签；注入某群细胞不得让读出报出未注入的通道（假阳性为 0 才算合格）。
3. 结果只能写成"对某群体的干预 → 内部活动 → 盲读出"，不得写成理解、意图或对话。

## 7. 现状

- 面板与编码已可用；未新增任何把自然语言直接映射为神经事件的路径。
- 与正常聊天的分界由契约与测试共同保证（`tests/test_environment_message.py::test_chat_never_passes_even_legacy_plan_items_to_neurons` 等）。
