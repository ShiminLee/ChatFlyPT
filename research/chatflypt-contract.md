# ChatFlyPT 架构与职责约定

依据用户历次要求及 2026-09-24 最新纠正：“我要求的路线是什么，照着那个复现”。按 chetaslua 公开演示的内部活动读出路线生成文字，不再要求先实现物理发声或化学释放。后续修改必须区分“人的消息翻译成感觉输入”与“外部模型替果蝇决定下一步”。前者是必要输入层，后者不属于本项目交互通路。

本文件后半保留较早阶段的验收经过。当前实现以本页前部的单个 MaleCNS、环境输入、10 ms 身体反馈、100 ms 眼图及跨几何编辑延续规则为准；后文曾使用的多连接组、100 ms 全感觉反馈、粗口器味觉和物品编辑后重置均不是当前规则。最终版本证据统一见 `reports/unified-pathway-20260924/README.md`。

## 完整信息流

人类聊天消息 → 语义解析 → 物理环境呈现（物品、场或碰撞探针）→ 实测眼图／感受器位置／物品接触 → 感觉转导编码 → 连接组内部演化。

依据用户同日最新纠正“感觉应该从环境来”：正常聊天只能使用环境采样输入，禁止把聊天翻译项另编码成神经事件并与环境事件合并。保留的直接神经干预仅用于明确标记的独立实验，不共享正常聊天的神经／身体会话。缺少物理呈现的模态不得用直接注入兜底。

接收后的记录分为三条路径：

1. 输入翻译、实际接收细胞和内部感觉读出证据 → 接收框中的“果蝇 · 感觉读出”。
2. 内部活动 → 盲读出器预测的有限标签 → 忠实自然语言 → 聊天框中的“果蝇 · 神经读出”。不直接复述输入方案；不拿人的意图、运动指令或 LLM 猜测当输出。没有活动、没有识别结果或未校准入口时保留无回复；持续反馈分布上的预测明确标为候选。不同连接组分别显示。
3. 运动相关神经活动 → 身体控制适配器 → NeuroMechFly 物理仿真 → 动作显示。

正常具身通路使用一个 MaleCNS 脑与身体：身体/环境变化 → 每 10 ms 的身体/接触采样及每 100 ms 的官方眼图 → 同一神经状态继续演化。膜电位、电导、不应期、延迟队列、身体和控制器跨消息、物品增删移动保留；环境重编译前后显式校验完整物理积分状态。等候消息时仿真时钟暂停。新对话、更换地面/系留身体场景以及服务重启会初始化新状态。会话最多记录 60 秒仿真时间，达到上限明确停止而不偷偷重置；无会话 ID 的独立实验仍重置。保留动态状态不等于语义学习、突触可塑性或自主生活。

## 组件与要求

| 组件 | 职责 | 必须遵守的要求 | 当前实现 |
|---|---|---|---|
| 人类聊天界面 | 接收人的自然语言，显示神经读出的表达 | 用户不必输入实现命令；不把模型建议冒充果蝇表达 | `web/index.html`, `web/app.js` |
| 语义与环境翻译 | 将人类消息变为环境呈现 | 例如“左转”译为右前腿物理探针；物品摆放按实际胸部朝向；不能选择神经事件或指定身体动作。未知语义与未实现物理模态明确不执行 | `environment_message.py`, `scene_language.py`, `physical_touch.py` |
| 神经输入编码 | 选择实际感觉细胞、侧别、强度、时序并生成输入事件 | 保留来源、细胞 ID、参数和输入记录；不同连接组的 ID 不混用 | `sensory_catalogue.py`, `sensory_events.py`, `social.py` |
| 果蝇神经仿真 | 按连接关系与动力学传播输入、产生内部活动 | 由神经模型产生响应；不能用 LLM 推测结果或预设应当服从人的指令 | `brain.py`, `malecns.py` |
| 感觉读出 | 从内部活动解码有限感觉标签，保留接收框证据 | 排除直接输入和感觉细胞的答案泄漏；读出接口只接受内部神经记录 | `experiment.py`, `state_readout.py`, `sensory_readout.py`, `dialogue.py` |
| 神经读出表达 | 将盲读出的内容译成自然语言，显示在聊天框 | 可使用第一人称模板，但不声称自主意图或任意句意；保留候选限定与无响应；不拼接不同连接组为同一个体 | `expression.py`，不需要 LLM 或物理发声；`acoustic_readout.py` 是独立可选研究模块 |
| 环境编辑与采样 | 编辑三维物品，应用后参与物理碰撞与官方双眼渲染 | 草稿为虚影且不生效；应用先进行真实环境采样和神经/身体响应，成功后发布环境版本并显示“环境改动”；独立“物理观察”用于无神经的机械检查 | `environment.py`, `environment_inspection.py`, `web/environment-editor.js` |
| 动作读出与身体 | 把运动相关活动转换为物理控制量，运行真实身体轨迹 | 采用已有 Bad Apple Fly / NeuroMechFly 控制器；控制输入只能来自实际神经活动，不能来自人的目标动作或 LLM 建议 | `behavior_readout.py`, `behavior_body.py`, `body-view.js` |
| 状态与感觉反馈 | 在连续运行中把身体/环境结果送回神经系统 | 必须基于实际环境/接触/感受器状态，不能用模型虚构；分段处不得重置状态 | `neural_session.py`, `body_feedback.py`, `embodied.py`, `proprioception.py`, `live_environment.py`；身体 10 ms、眼图 100 ms，跨消息与几何编辑延续，等待消息时暂停 |
| 可视化与证据 | 展示输入翻译、神经响应和动作及其对应关系 | 左侧聊天；右侧上方神经图、中间接收说明、下方身体；可回放且记录不混淆 | `visualization.py`, `server.py`, Web UI |

## “左转”例子

- 聊天输入：**左转**。
- 中间接收框：**用真实碰撞探针尝试触碰右前腿**，另列是否实际测得接触及输入记录。探针参与 MuJoCo 碰撞与双眼渲染，页面回放使用它的实际位置。
- 只有测得接触才由环境转导产生触觉输入；神经模型自行传播。没有接触不得补发聊天刺激。
- 若内部活动确实盲读出右前腿触碰，聊天框可显示“我感到右前腿被碰到了”，标注“果蝇 · 神经读出”；接收框保留输入方案和感觉证据。
- 若属于持续环境试次，在句子前标明候选。使用下述有限反馈适配器时显示“候选神经读出（连续反馈仅有限验证）”，否则仍显示“连续反馈尚未校准”。未识别、无活动或入口读出未校准时不强造句子。读出触碰不意味着已经执行左转。
- 身体是否左转、产生其他反应或没有动作，取决于运动相关活动及当前身体模型；不能把“左转”直接赋值给动作输出。

方向到对侧触碰是当前工程编码约定，尚不等于已经验证的自然语言语义或必然左转反射。它属于用户消息的翻译，不能因此删除它，也不能宣传为真实语言理解已经完成。

## 大语言模型的边界

目前已有“内部活动 → 标签 → 文字”的实现不需要大语言模型。当前主通路不调用 GPT/Qwen，不用它自由编造果蝇答复。

将来如加入 LLM，只能作为经过单独验收的语言处理工具：帮助解析人的表达，或忠实改写已经读出的内容。它没有自行生成目标、选择下一步动作或触发额外神经输入的权限。

**禁止恢复：感觉读出 → LLM 自行给行动建议 → 把建议回灌感觉神经。** 这会使外部 LLM 成为决策者。人类发送消息的输入通路与此不同，必须保留。

## 完成标准与现状

2026-09-24 后续修复：正常环境通路已统一到单个 MaleCNS，不再以两个独立身体冒充同一个体。官方复眼画面经候选局部小眼配准进入 R1–6；嗅觉、温度和接触入口按同一连接组注释选择；真实腿角与角速度经发表的 claw/club 群体函数回传。300 ms 连续物理验收、两次物品增删和累计输入重放已经通过，见 `reports/unified-pathway-20260924/acceptance.json`。这证明实际有限通路运行，不代表感受器全覆盖、空间配准或生理增益已经标定。

本体感觉现有 223 个有模型出边的 claw/club 候选入口；归一化钙活性到事件率为工程增益，hook 方向、campaniform 负荷转导及高频振动仍缺。环境几何变更保留动态状态。高盐进食姿态、强触碰无可用避让以及旧热源读出误报仍是未通过的反例，不因软件接线修复就算消除。LB3d 的官方型级共识为 26 个 ACh，个体预测则为 11 ACh、7 glutamate、8 unclear，不能把前者写成单细胞实验真值。证据见 `research/lb3d-transmitter-followup-20260924.md`。按真实情况验收须对照实测感受、内部响应与实际行为，不用目标动作兜底。

**复现范围须单列：** chetaslua 公开的有限词汇“内部活动读出 → 感觉句子”已完成独立功能重建，展示组合存档 20/20 可再读出。该演示复现不以物理发声、化学释放或 DAS 分类器为前置条件。最新用户要求已取代此前“聊天只能显示物理对外信号”的限制，现将该神经读出表达接入聊天。作者完整源码、权重和词表未取得，因此是独立功能重建，不是逐行或精确数值复制。公开演示未证明开放语义；历史独立试次成绩也不等于当前持续环境下已校准。

已具备有限感觉输入翻译、连接组仿真、神经读出语言表达、神经驱动身体回放与界面联动；环境物体碰撞、官方双眼及复眼渲染、本轮内感觉反馈已接入。浏览器会话已有跨消息动态状态延续；开放的任意人类语义翻译、长期学习及完整视觉配准仍不能称为完成。连续反馈读出新增下述有限场景验证，仍未完成全词表、新环境或生物学层面的校准，其标签必须显示为候选。接口的完成标记只描述当前有限词汇试次，不能当作整个项目或任意自由聊天完成。

转向一项在 2026-09-30 分成两条互不冒充的线：实测运动读出继续对"转向"弃权（该语料命令幅度太小，身体转不出来会被步态偏置淹没）；另加一条**自身转向指令读出**，读的是它自己下发的命令、明确标注未经行为验证，方向词由合成命令实测标定、并按每方向验证支持只服务"向右"（见 `reports/command-readout/README.md`）。这条线读的是命令，不是身体是否跟随，也不是主观意图。

提问一项同日补齐：**问题只路由到测量它的那一条读出**（走/停、转向指令、感觉、实测接触、实测身体状态），答案句自带出处与弃权原因；问句形状只决定"允许路由"，不构成理解，未知问题仍按未解决输入拒绝，LLM 不在回路里，也不重跑仿真。路由实现 `chatflypt/questions.py`，实况验收 `scripts/check_question_route.py`。

定向诱导轮（`conspecific-v6`，2026-09-30/10-01）：在冻结语料上追加 72 会话（扩展链验证，不重采旧语料；72/72 完成，联合语料 438 窗）。一半成了、一半没成，都写清楚：**左转命令采集出来了**（有效左转窗 1 → 6，验证集 4 个）**但读不出**（验证集符号正确率 0/4，右转 26/27），因此方向门槛收紧为"支持 + 逐方向符号正确率"，`served_directions` 仍只开"向右"；**气味/温度的左右对照采集不出来**（双侧投递接近对称，中位比 0.77–0.85，主导式转录规则实测被证伪），四个侧标签保持弃权并写明是**器械所限**，见负面登记表。方法借自记录语言学（覆盖率矩阵驱动定向诱导、负面证据、旧记录不重解释），记在 `research/elicitation-methods-20260930.md`。另一条真实约束：扩语料后再改采集脚本会被模型快照守门拒绝续采，改代码扩语料须另开一轮。

第二轮诱导（`conspecific-v7`，2026-10-02/03，108 会话全部完成）与 v8 发布：按覆盖率矩阵把 12 个未合格标签里"能诱导的"逐个处理，结果如实分成三类。**（一）补出来了**：验证过的定点单侧源重复把左右对照真正做出来，`warm:left`、`cold:left`、`cold:right` 三个侧别标签合格（验证集 precision 0.93–1.00、recall 0.78–0.88），统一读出发布件由 18/30 升到 **20/30**。**（二）补出来了但读不出**：左转命令仍在验证集里没有有效窗（语料变大后训练分位阈值从 0.0119 升到 0.0165，第二轮诱导出的左转命令大多落在阈值之下），方向门槛如实扣词，线上仍只说"向右"。**（三）看着有其实没有**：`yeast:right` 在 v5 里合格是因为当时语料偏侧（43:1），换成两侧等量的语料后酵母左右读不出；"阈值尺度"这个解释已实测排除（改用训练分位数阈值结果不变，存下的阈值也在网格中段）。因此发布件**丢掉酵母标签**而不是保留一个未验证的侧别，并记入负面登记表。另外查明并登记一条实测缺陷：`anchored`（跟随源）实现对每个受体重摆源，构造上不可能有侧别——修它要动契约哈希内的转导代码并整批重采，留作单独一轮。翼/背板接触标签的感器图谱在文献里存在（Lesser 2025 / Ghysen 1980），属"可做但需配准子项目"；唇瓣在钉版身体上没有网格，需先改身体模型。

**锚定场缺陷已修（2026-10-03）**：`measured_field` 现在认 `anchor_side`，源只跟随**自己那一侧**受体。真机验证（`scripts/check_side_delivery.py` → `reports/unified-readout/side-delivery-probe.json`）：四个条件各一窗，**本侧 8–18 个实测事件、对侧恒为 0**（旧行为是 12/12 双侧）；纯函数单测另见 `tests/test_anchored_field.py`（远侧恒 0，动物移动后仍为 0，未声明侧向的旧场景逐字节不变）。因 `environment.py` 在契约哈希内，已按纪律**整批重采**为 `conspecific-v9`（393 集 = 原联合 321 + 新 72：54 个声明侧向跟随源 + 18 个镜像转向合刺激），空间配准图按项目流程重拍重建成**位级相同**（`71fbfa7b…`）。

**v9 重拟合与发布（2026-10-04）**：四条读出全部在 v9 上重拟合，按各自预注册门槛决定去留——**统一读出 19/30 合格**（新增 `cold:left`/`cold:right`/`warm:left`，验证 P 0.92–0.93、R 0.76–0.93；落榜 `yeast:left/right` 与 `warm:right`，在两侧等量语料下稳定 `tp=0/fp=0`，即"看到有其实读不出"），发布 `cbd72e06…`；**命令读出**右转验证符号 36/36、零命令误报 0/138 与 0/135，左转仍弃权（有效左转窗全语料 4 个、验证集 1 个且符号错），发布 `9c3c76e2…`；**槽位读出**合格（sustained + 三档活动），发布 `e6127ec2…`；**运动意图读出在 v9 上不合格**（路径相关 0.567 达标但位移门 precision 0.677 < 0.85），**如实弃权、不发布**——线上"运动意图"一行因此显示未合格，而不是继续用旧权重。实况复核：`右侧有酵母` 的感觉读出只报 `bright:left/right`（不再报未验证的酵母侧别），意图行为空。

## 同种通信、运动侧读出与方法层（2026-09-29 第二批）

按"人经果蝇之间的沟通方式转码、果蝇侧读出感觉与意图、方法上借田野语言学"的要求新增。以下每条都只写在实现与验收完成之后，未完成的部分单列。

- **触碰节奏（同种接触）**：物理探针支持敲击序列（`taps` 1–8、`interval_ms` 开启到开启间距、每次敲击在开始时按当前腿姿重新瞄准）。同种接触的毫秒级时长在可及文献中查不到（Ramdya 2015 只给"轻触远端腿、右腿触碰倾向左转"这类定性结论），因此**时序全部标为工程参数**，不假装是实测值。呈现层报告**逐次接触**（`measured_contact_bouts`）而不是 10 ms 窗口数。语言层支持"连碰三次""碰三下"等说法；默认单次敲击 60 ms，未指定时长时不再沿用 300 ms 长按。

## 组合式表达与两个新增盲槽位（2026-09-30 第三批）

原构想里"高维生成（目标）"这一步，按契约的边界实现为**接地组合式渲染器**，而不是让语言模型替果蝇说话。

- **新增两个盲槽位**（`chatflypt/slot_readout.py` + `scripts/train_slot_readout.py`）：`activity:quiet/moderate/busy`（真值＝窗口内**非感觉非输入**脉冲数，训练集 33/66 分位为界；三档全部合格，测试 micro-F1 0.888）与 `pattern:sustained/transient`（真值＝窗口内**实测投递样本占比**，阈值 0.3；只有 `sustained` 合格，且在本语料近乎恒定 96/98，如实记录为"近乎退化的槽位"）。同一盲掩码、同一资格门槛、不合格即弃权。
- **组合式渲染器**（`chatflypt/generative_renderer.py`）：按"内部活动 → 各感觉通道（连接词）→ 时间形态"组合成句，措辞按 `(槽位, seed)` 哈希在 2–3 个变体里确定性选择；**不能**引入未解码的槽位、修饰或因果；无合格槽位时不生成句子。没有槽位读出时自动回退到逐通道模板，作者示例句保持逐字不变（`tests/test_expression.py` 仍断言原句）。
- **可审计的接地**：`audit_grounding()` 逐句核对当窗**实测**事实，分开报告 **invented（虚构槽位）/ unsupported（无实测支撑）/ contradicted（解码与实测不符）**。conspecific-v5 测试集 98 窗实测：**61 个不同句子、invented 0、unsupported 0、contradicted 12（12.2%）**，每条矛盾都带实测值留档（`reports/generative-renderer/`）。
- **与语言模型的界线**：本层不含任何语言模型，措辞来自固定语法、内容来自盲读出。用预训练 LM 生成句子属于**单独标注的实验**（见 `research/flm-experiment.md`），不得进入聊天通路——"不调用模型代替果蝇说话"仍是红线。

## 运动通路诊断：为什么"转向意图"拿不到行为标签（2026-09-30）

三次转向读出失败（v3 离散 1–6 个验证正例、v4 连续 r=0.078）的根因不在读出器，而在**标签来源**：

- `command_summary.left/right` 是**左右腿踏步驱动**（`vendor/badapple-fly/backend/evidence.py:95-101`），转向编码在两者的**不对称**里且符号相反；本仓库早前把它当作"转向命令"是误读，已在 `reports/corpus/negative-registry.json` 与 `reports/intent-readout/README.md` 更正留档。
- **系留飞行线程写死为零**：`if context=='tethered_flight': left=right=0.`。实测对照（地面 9 窗 vs 系留 9 窗）证实系留模式下命令/偏航/位移全为 0，因此系留在本版本里不可能提供转向行为数据。
- 地面：不对称驱动窗口的偏航只有 ~0.3° 量级，而**无驱动**窗口的偏航标准差 3–7°（极值 −19.9°/+59.1°）。即被驱动的转向被身体自身动力学/滑移淹没。

因此：**行为验证的"左/右转"标签在当前钉版控制器+身体上不可得**。要让它成立必须改运动通路（让驱动的不对称产生可辨净转向），这会牵动上游钉版控制器与全部语料指纹，属需要单独立项的工程决定；在此之前转向保持弃权，且不允许用"命令标签"替代行为标签（那会变成自我循环）。

### 更正与落地（同日，合成命令标定 + 命令读出）

- 上面"不对称只产生 ~0.3° 偏航"是**语料里实际出现的**幅度，不能推成"身体转不动"。合成命令标定（`scripts/probe_command_sign.py`，每次只让一个已映射运动群单侧活动，地面 500 ms，每条件 2 次）显示：不对称 0.34–0.76 时 500 ms 内**实测转 22–46°**（turn_inside 左 +46.3/+30.2°、右 −39.0/−30.8°；turn_outside 左 +29.2/+22.8°、右 −27.6/−22.5°），对称条件（不对称≈0）符号不一致、|偏航| 3–9° 为地板。故真实原因是**语料中的指令幅度（最大 0.083，85 分位 0.012）比能转起来的量级小约 5 倍**，再叠加步态偏置。记录：`reports/command-readout/controller-sign-probe.json`。
- 符号由此**实测确定**：右腿驱动高于左腿 ⇒ 左转（正偏航），四个不对称条件两次重复全部一致。标定只用于给命令读出命名方向，不驱动任何会话。
- 上面的"不允许用命令标签替代行为标签"**仅限把它当作行为验证**：读出**它自己下发的**转向指令并明确标注"命令读出、未经身体行为验证"，按用户 2026-09-30 的指示即为本来要读的对象（粘体文本的有限读出路线），不算自我循环——防循环靠**特征排除全部已映射运动群细胞**（命令是这些群速率的纯函数，读它们等于复述公式），并同时报告"仅运动群"天花板对照。见 `reports/command-readout/README.md`、`chatflypt/command_readout.py`。
- 口径修正：`command_summary` 是窗内 min/max，每个窗口第一帧永远是零命令字典，因此**全负（后退）窗口的 `max` 读作 0**，会被误算成"无命令"；命令读出改用轨迹帧均值，受影响的旧审计数字以新口径为准。
- 落地结果（conspecific-v5，294 窗，各 98 训练/验证/测试）：命令读出**整体合格**（验证 r = 0.787、有效命令窗符号一致 15/16、零命令误报 1/57；测试 r = 0.869、符号 12/13、误报 4/58），294/294 窗标签由记录脉冲重算并逐位复现；控制：打乱标签 r = −0.057、全零输入 0.0017、仅运动群天花板 r = 0.85–0.87（与盲读出接近）。方向支持按**每方向**门槛（验证集 ≥ 2 窗）：本语料有效命令 44 窗中 43 窗向右、1 窗向左，因此只服务"向右"，"向左"即使被预测到也不发音（`served_directions` 写入产物元数据）。

## 环境输入的准确含义

- 糖、盐、酵母、方块的实体几何既参与碰撞，也进入双眼渲染。看到实体不等于已识别其化学成分。
- 官方 Retina 每眼 721 小眼记录被保存。正常通路按 R1–6 到 L1/L2/L3 实际连接边推定视网膜列，经同 body ID 交叉表关联作者 MaleCNS 光轴，再投射到实际眼相机与 Retina；未使用神经元编号排序。当前接受 2,322 个受体（左 713、右 1,609），拒绝 1,055 个无可靠匹配或不在实际视场的受体；不回退到旧矩形归一化或眼均值。40/40 作者光轴亮斑的实际渲染检查通过，但跨标本感受野、图谱版本选择和生理转导仍有不确定性，不声称物体身份识别。旧 FlyWire 实验仍为分眼均值。
- 酵母气味在实际 funiculus 位置采样工程距离场；热/冷在实际左右 arista 位置分别采样，同侧有符号场先合成，净正值进入温暖入口、净负值进入冷却入口。热源参数不是摄氏度，气味不是实测浓度，静态场也不等于受体的完整时间响应。
- 官方身体尚无已注册的 labellum 味毛表面，rostrum/haustellum 碰撞只记录为未映射口器接触，不驱动唇部糖/高盐群。糖实际接触跗节时，按前/中/后腿、左右入口选择 MaleCNS LgLG4/LgAG2 候选群，不替代为口器细胞。受体归属以论文的形态/投射匹配为依据，非精确感器或强度标定；胫节虽有味毛，但现有候选桥接尚未核实该部位。高盐腿部入口仍未映射。旧口器糖/高盐试次只作历史证据，不能在新训练中按物品名补出未投递的标签。
- 光源参与实际渲染；暗区是区域内的视觉衰减，不注入虚构的“暗”神经。
- 草稿不送后端；应用经过物理感受器采样、感觉事件、神经与身体响应后原子保存。独立“物理观察”不调用神经仿真、感觉编码器或 LLM。每份记录保留环境版本，神经响应存于 `reports/environment-responses/`，独立物理观察存于 `reports/environment-inspection/`。环境输入不能直接覆盖运动指令。
- 正常聊天默认每 10 ms 重新测量身体与接触、每 100 ms 更新眼图，反馈同一神经状态。人的触碰提示在物理世界中执行固定轨迹；感觉入口侧别来自碰到的腿，而不是目标腿标签。探针半径 0.06 mm、前进与退出各 50 ms，强度改变有限几何压入量，未校准为真实触碰力。探针不追踪身体。短于采样间隔的接触仍可能遗漏。
- MuJoCo 的接触列表不等于表面已经接触：只接受已激活接触约束、几何距离不大于零且另一端为果蝇身体的物品接触。记录模型原生单位的法向／切向力，但尚未建立受力到神经放电的生理标定；不会把近距离 margin/gap 记录当作味觉／触觉。
- 糖、高盐、酵母、热／冷源、光源、暗区和方块可以由简单物品语句呈现；默认身体指定方位 3 mm 处，未指方位则前方。新物品应用后保存环境、显示“环境改动”，保留当前会话神经/身体状态。复杂摆放与尺寸仍用环境编辑器。醋、声波等没有物理呈现的旧实验通道不得进入正常聊天。物品仍在时不能用“停止刺激”抹去其真实感觉。
- 同一浏览器会话跨消息保留状态，等待消息时暂停；新对话及独立实验重置。物理触碰探针预先编译；新增／移动／删除持久物品时使用可编辑模型重编译并保留积分状态、神经与控制器，不再重置。

## 环境唯一输入修复验收（2026-09-24）

- 正常聊天及旧 `/api/receive` 入口不再调用直接刺激通路。应用环境也使用 `environment_only`；服务端及具身入口均拒绝该模式下携带直接神经输入。无身体后端时明确失败，不回退注入。
- 接触探针和空环境、远糖三条 500 ms MaleCNS 记录均无 MuJoCo 数值警告。空环境、远糖各 0 个感觉事件；探针在 100 ms 实测右前足接触后产生 235 个触觉事件，0 ms 时没有提前输入。三条神经结果均与已记录事件磁带逐项重放一致。不能据此声称避让、转向或开放语言已完成。
- 所有聊天输入只来自实际环境转导仍不意味着生理转导已校准；分眼平均亮度、候选腿味觉、100 ms 采样及有限神经读出限制保留。详细证据见 `reports/environment-only-20260924/`。

不能仅因一次接口往返成功就声称完整架构完成，也不能把移除外部控制等同于已经构建自主生命体。

## 环境与物理观察验收（2026-09-20）

以下是此前独立物理观察版本的历史验收；环境应用已被下节的神经响应通路替代，独立“物理观察”功能仍保留。

- 编辑器支持同一环境版本的浏览器草稿恢复、复制物品、最多 50 步撤销/重做、非法几何拦截。刷新只恢复草稿，不自动应用。
- “应用环境改动”先运行 500 ms 物理检查，成功后保存新版本及 UUID 记录。失败不发布新版本。“物理观察”重测当前已应用环境，不改变版本，也不应用草稿。
- 观察使用固定版本 Bad Apple Fly 身体与 MuJoCo。沿用固定姿态预热，随后关闭全部执行器；窗口内位移是机械过程，不作为神经驱动动作或主动行为证据。观察模式额外为身体网格加入地面/物品碰撞，防止无动力倒伏后躯干穿地；原神经动作通路仍使用原碰撞配置。系留仍是显式运动学约束。
- 独立回放时间线每 20 ms 保存位姿及物品接触，开始/中间/结束保存原始双眼画面和官方 Retina 小眼数值、复眼拼图。三张画面不是连续视觉视频；接触采样可能遗漏短暂碰撞。
- 聊天区显示系统“环境改动/物理观察”事件，可查看记录与导出 JSON。此记录不产生“果蝇 · 表达翻译”消息。
- 记录路径：`reports/environment-inspection/<uuid>.json`；旧 `reports/environment/` 中的神经试次是历史记录，不能混同新物理观察。

## 环境到神经响应与场景消息修复（2026-09-20）

- 环境应用重新接入感觉编码、独立连接组仿真及身体回放；新版环境记录可在刷新后恢复。身体物理失败不发布候选环境。
- “糖在哪里”等位置问句触发新的环境观察，而不是读取不存在的旧表达。问句的“在哪里”含义尚无感觉码本，不能把重新采样宣传为果蝇理解或回答了问题。物品坐标只能用于人的指代解析及验收，不能作为读出器的答案。
- “走到某物品的位置去”等目标输入通过通用物品词表解析。多对象时要求明确左/右/最近等指代；负向、条件及复合语句不截取执行。按实际胸部姿态把一次初始左/右目标提示译为对侧前腿触碰。没有为正前方前进编造感觉编码，也没有自动目标追踪器。
- 距离变化和目标接触只在身体记录产生后计算；没有运动命令时的姿态维持/重力位移不是自主行动或成功完成目标。两个连接组的观察和身体记录分别标识，不构造成同一只个体。
- 新增腿部味觉采用 [Cell 2026 味觉连接组研究](https://www.sciencedirect.com/science/article/abs/pii/S0092867426009438) Fig. 3J/4J 的候选受体匹配，详见 `research/scene-pathway-evidence.md`。按实际接触腿及侧别挑选 ID，新的候选群不能套用旧口器读出器的语义标签。
- 本次神经身体回放也启用与环境探测一致的完整身体碰撞，固定版本上游控制器源码未改动。
- 完整自由聊天仍未达到：缺少小眼到连接组列的空间配准、跨消息状态延续、对外声/化学信号的测量和语义解码。软件测试通过不等于这些科学能力已具备。

## 本轮内感觉反馈验收

- 同一个隔离物理进程持续推进身体，每 100 ms 采集真实接触、位置与官方眼图。同一个神经会话继续运行，不清除膜电位、电导、最近脉冲、不应期、活动集合或延迟队列。
- 每段运动命令只使用时间上已完成的神经脉冲箱，保持原控制器与因果滤波。没有加入目标位置控制器，也没有调用 LLM。环境接触的机械瞬态在持续接触时继续衰减，不因分段重复起始触碰。
- 人类输入与环境输入为独立事件源；保留同时发生的事件。实际输入事件及最终神经/物理状态均存档。另一连接组的入口列入排除记录，不混入 ID。
- 页面神经与身体按同一时间线回放，双眼图切换到对应采样时刻。完整采样与状态哈希见 `embodied_feedback` 记录。
- 小网络跨 1.8 ms 延迟/不应期边界的分段结果与旧内核逐项一致；真实 MaleCNS + 糖平台 + MuJoCo 的 300 ms 三段反馈通过完整输入磁带重放一致性检验。

## 重放与页面复验（2026-09-24）

- 每个输入细胞第一次成为输入的时间步也必须存档。新发生的接触不能在重放时被追溯为试次起点已有的刺激；否则会提前改变该细胞的不应期。`input_activation_steps` 与事件时间、细胞 ID 一起保存，`neural_session.replay_events` 按边界恢复。
- 页面实际发送“糖在哪里”和“走到糖的位置去”，所得三个连接组记录均经过独立神经重放。计数、脉冲细胞、脉冲时间及膜电位统计逐项完全一致。两个消息各有 500 ms、5 次感觉采样；眼图回放的 0/500 ms 帧不同，页面控制台无错误。
- 目标测试的 MaleCNS 有 921 次脉冲、628 个活跃细胞，但没有当前控制器可用的运动命令，也没有糖接触；不能将它报告为主动到达目标。位置问句没有产生位置回答。验收结果见 `reports/scene-pathway/embodied-browser-acceptance.json`。
- 推理服务不再在启动时导入训练专用的 scikit-learn；这些导入延迟到训练函数。此项解决了本机启动被训练依赖卡住的问题，没有改变读出结果或扩大词表。

## 跨消息会话的历史验收（早于单体环境编辑修复）

- 浏览器发送会话 ID，每个连接组仍有各自的神经/身体状态。方向指代从对应身体的当前胸部姿态计算；同一个名字的物品不会成为读出答案或自动导航目标。
- 连续消息只清空本条消息的被动统计和回放窗口，保留神经电位、突触电导、延迟队列、原控制器及物理状态。动作滤波继续使用完整已记录的神经时间序列，不能从用户意图产生动作。
- 累计输入事件、首次输入时刻及累计原始神经记录保存在每条消息的具身目录；继续运行的单条消息磁带必须带之前的完整输入前缀才能从静息状态重放。
- 刷新页面可恢复服务器仍存活的会话最新记录；“新对话”关闭相应物理进程并释放状态。服务重启不自动还原存档；记录文件不能冒充已经恢复的运行状态。
- 环境或身体场景变化时明确标注重新初始化。任一连接组已经前进后本轮失败，会停止同一会话所有连接组，避免部分前进后重复执行消息。
- 真实糖平台 100 ms + 200 ms 两条消息与一次 300 ms 不中断实验，累计神经记录及最终身体位置逐项完全一致；第二条消息的神经/身体重置次数均为零，起点神经状态哈希等于前条终点。
- 浏览器连续发送“糖在哪里”“走到糖的位置去”“左转”已验证会话延续，但仍未产生有依据的对外表达或到达糖的结果。
- 本节取代历史验收段中“消息之间仍重置”的状态说明；具体文件见 `reports/persistent-session/`。

## 声学读出验收（2026-09-24 后续）

- 接入 DAS 作者公开的 Dmel_single_v1.0 原始权重，输入只接受 10 kHz 单声道真实波形；输出为 noise/sine/pulse，不接受人的消息、感觉标签、目标或运动命令作为特征。
- 原权重转换为明确的数值图；不执行旧模型内序列化的 Python Lambda。与独立 NumPy 算法比较，最大概率误差 8.35e-7。分块使用完整感受野，避免边界补零造成假的声学事件；需 144.3 ms 后续上下文，全局边缘不分类。
- 作者随模型发布的 112.4352 秒录音上，逐采样 F1：持续鸣声 0.9613，脉冲鸣声 0.8416。该录音与作者训练的重叠未知，不能写成独立动物测试或用总体准确率替代各类结果。报告：`reports/acoustic-readout/das-acceptance.json`。
- 外部录音不属于当前仿真个体。当前身体没有校准声压/粒子速度、化学释放或基底传播模型；分类器不会凭神经元标签或展翅动作合成声音，也不会为聊天生成第一人称意图。
- 当前仍没有可验证的任意人类句意码本。声学类型识别、行为语境推断和开放语言语义是不同任务；不得把前者通过验收改写成自由聊天完成。
