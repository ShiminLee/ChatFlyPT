# 空间视觉接入核查（2026-09-24）

当前身体保存官方 Retina 每眼 721 个小眼读数，连接组输入仍使用分眼平均亮度。现有候选六角网格不能直接替代小眼到神经列的配准。

核查的主要来源是 Zhao 等人的 [Eye structure shapes neuron function in Drosophila motion vision](https://www.nature.com/articles/s41586-025-09276-5) 及作者 [eyemap_T4](https://github.com/reiserlab/eyemap_T4) 代码。项目内已下载的版本、文件和哈希见 `sources.json`，本次没有下载新的权重或改写视觉通路。

作者通过微 CT 眼表面和视神经列的规则网格、形态标志建立眼方向映射；使用 FAFB 雌性果蝇的 CATMAID 重建，代码内的 Mi1 和眼模型行名承担匹配。它不是本项目 FlyWire/MaleCNS 细胞 ID 与 MuJoCo 摄像机之间的现成转换表。论文另使用的雄性视叶数据也不能直接当作当前 MaleCNS 全脑版本。

目前还需形成并验证以下三个接口，才能将候选资料接到运行中的空间视觉：

1. 作者神经列/CATMAID 标识到本地版本连接组细胞 ID 的可追溯对应，包含半球、重复与缺失检查。
2. 作者眼方向到 NeuroMechFly 左右眼相机坐标的旋转、朝向与视野配准；用独立左右、上下移动图案验证，不能只凭编号顺序连线。
3. 每个小眼亮度到光感受器输入的转换及独立响应验证。当前 LIF 电响应并非已标定的真实光感受器生理模型。

候选匹配审计中的 3,162 个细胞和 786 个列只描述候选覆盖，不意味着上述接口已验收。先保留均值桥接与原始小眼记录，避免将未经核对的空间方向送入神经系统后误报“已看到物品位置”。
