# LB3d 递质分歧：逐细胞预测、官方共识及默认模型的边界

2026-09-24。此次仅核查并保存证据，没有改动默认神经图、感觉磁带或运动规则。

## 本次实质发现

“26 个 LB3d 全部被自动预测为 ACh”不够准确。对本地 MaleCNS v1.0 官方注释按精确 `type == LB3d` 联接官方递质表，结果如下：

| 字段 | 结果 |
| --- | --- |
| `consensus_nt` | 26 个全部 acetylcholine |
| `celltype_predicted_nt` | 26 个全部 acetylcholine |
| `predicted_nt` | 11 acetylcholine、7 glutamate、8 unclear |
| `ground_truth` | 26 个全部为空 |
| 型级 `celltype_predicted_nt_confidence` | 0.6286705668070036 |

7 个单细胞 glutamate 预测的 MaleCNS body IDs：`130693, 140851, 201075, 236475, 261048, 516216, 550065`。预测置信字段约为 0.507–0.635。其余逐细胞值、侧别和每个聚合所用的突触预测数见 `reports/lb3d-evidence-20260924/lb3d-official-neurotransmitters.csv`。这份 CSV 是从本地官方原始文件精确提取，**不是 Table S1**。

原始文件来源是 [MaleCNS 官方下载页](https://male-cns.janelia.org/download/)。原始文件 SHA-256、全部 ID 和下载核查状态见同目录 `summary.json`；NT 原文件 SHA-256 为 `95c9289220663abeb3409f3ad9e5a7f8a53f8093f5139d15502cd08da8879621`。

## 为什么官方共识覆盖了单细胞分歧

这不是本项目临时编造的型级替代。Janelia FlyEM 官方 `flyem-snapshot` 导出代码定义了 `consensus_nt`：先取型级聚合，有明确实验真值时再覆盖；未分型细胞才以自己的预测作为共识。见固定版本 [neurotransmitters.py 的 `_set_body_exp_gt_based_columns`，第 720–753 行](https://github.com/janelia-flyem/flyem-snapshot/blob/2218084291111da470ff1c2d74d9d74cddcce65c/flyem_snapshot/inputs/neurotransmitters.py#L720)。源码和 BSD 3-Clause 许可证已原样保存到上述报告目录。

因此有两层不同选择：

1. **官方数据整理选择：** 提供综合型级证据和实验覆盖的 `consensus_nt`，同时保留单细胞预测供审查。
2. **本项目神经仿真选择：** `chatflypt/malecns.py:31` 使用该官方共识，再经本项目 `SIGN` 表映射为突触符号。官方字段定义不等于官方证明它在当前简化动力学里能正确产生所有行为。

没有找到官方要求“默认必须改用逐细胞预测”的依据。使用官方共识是有来源的默认，不能仅因另一种符号使高盐停止伸喙而宣布默认代码错误。反过来，不能把该共识当成 26 个独立实验都确认 ACh。

`predicted_nt_confidence` 也不应直接解释为“该细胞有多少概率是某递质”。官方 `_compute_group_predictions()` 从 T-bar 分类的混淆矩阵计算组内均值；它不是已校准的单细胞身份后验概率。因此不建议直接把 0.63 当成兴奋权重、0.37 当成抑制权重来混合。

## 味觉论文到底证明了什么

[Tastekin 等，Cell 2026，图 2D/E 与对应正文](https://www.sciencedirect.com/science/article/abs/pii/S0092867426009438) 将 LB3d 与 Ir7c/ppk23 高盐相关谷氨酸群体作候选匹配，并依据其下游重叠提出抑制趋食回路的假设。文章明确保留匹配的不确定性；图 2E 的 Ir47a 形态对应本身也不是每个 EM body 的递质实测。

本轮没有成功取得官方 Table S1：期刊页面和候选补充文件端点返回 403；bioRxiv 补充索引请求返回 429。候选 URL 的 `mmc2.xlsx` 序号未能核实，不能称为已确定的 S1 地址，也不能称补充数据不存在。查询作者 MaleCNS 仓库和 Ribeiro 实验室公开仓库未发现该味觉论文的独立 S1 文件。以上只说明这次未取得文件，不能扩大成作者未公开。

即使取得 S1 并与这 26 个 body IDs 完全一致，仍需检查表中是形态/受体候选、分类器输出还是独立递质实验证据；单纯 ID 对上不能自动升级为单细胞谷氨酸实测。

## 可执行的工程建议

- **默认保留官方共识。** 把 UI/报告叙述改为“LB3d 官方型级共识为 ACh，单细胞预测分歧且无本地实验真值；文献提出谷氨酸高盐群体候选”。保留不确定性。
- **独立敏感性模型 A：** 官方共识，26 个 ACh。当前默认即为此模型。
- **独立敏感性模型 B：** 对这 26 个细胞显式读取官方单细胞预测，得到 11 ACh、7 glutamate、8 unclear。只能叫数据层级敏感性对照，不叫生理修复。未定的 8 个细胞必须单列；若沿用零快电流约定，要说明这是未定符号的工程处理，不是它们没有突触。不能覆盖任何已有实验真值，也不能把此局部对照偷偷推广到全图。
- **既有全 LB3d 谷氨酸对照：** 保留为文献候选假设 C，而非官方逐细胞模型 B。全翻 26 个与只翻 7 个并处理 8 个未定是不同实验，结果必须分别报告。
- 所有对照应重放同一份实测感觉事件、相同初始状态、相同记录窗口，报告 MN9、所有相关运动活动以及脑活动变化。不要按“盐能不能躲开”挑选默认模型。糖对照不变只能定位影响范围，不能验证递质身份。
- 真正解除分歧需要精确型/细胞匹配的递质实验或作者更新注释；进一步判断谷氨酸对应的突触效应还需要接收端受体/动力学依据。连接组形态和分类器不能单独提供全部信息。

本轮交付是可以复查的分歧定位和两种官方数据层级的明确比较方案，没有宣称高盐回避已经解决。
