# 人类语言 → 模拟果蝇接收：下一阶段方案

更新（2026-09-19）：用户指定优先使用果蝇已有的同种通信通道。当前主线已调整为“自然社会信号 → 对应感觉神经输入”，已实现输入字典、事件编码、连接核查与部分通道的下游仿真。详见 [当前方案与实测](social-communication-inputs.md)。

以下保留此前的**可选关联学习研究方案**，用于将来研究新增约定信号；它不是自然触碰、信息素或鸣声通信的必要前置。关联学习尚未实施，本阶段不依赖真实果蝇实验。

## 要检验什么

把“接收”分为：信号到达下游、跨时间保留信息、通过经验形成关联、用消息预测结果。现有工程听觉码本只验证了信号可经固定网络传输并由外部读出器区分；不构成网络学会消息含义。

首个里程碑：在训练后，只呈现一个约定信号、不给对应结果，模拟网络的后续活动仍出现可重复且依赖所学突触变化的结果价值预测。开始只检验正向/负向结果预期，不能据此宣称识别了糖/苦的具体身份，更不能宣称自由语言理解。

## 输入链路与模块边界

人类自由文字 → 受约束的消息解析器 → 语义协议 → 感觉编码器 → 神经活动 → 学习/记忆回路 → 独立测量。

- 自由文字阶段可先用固定测试句，后接 GPT。支持语义以显式白名单定义；否定、时间和不支持内容必须保留或拒绝，不能猜测后丢掉。
- 第一阶段仅两种消息，例如“接下来会有正向结果”“接下来会有负向结果”；未来结果不在测试时实际呈现。
- 编码器使用可区分、能量和时长匹配的 A/B 刺激模式，并随机对调消息与模式的分配。
- “通知有糖”不能直接变成向糖感受神经元施加糖刺激。传讯线索与实际结果须独立，才能检查消息—结果关联。
- 神经引擎接收神经元 ID、脉冲时刻/强度，不能接收中文、语义标签或预期正确答案。
- 接收后的测量器在接收学习阶段冻结，只看神经活动。不能通过重新训练外部分类器来冒充神经网络获得了记忆。

## 工程改动

1. 新建有状态 BrainSession：保留电位、突触状态、不应期、延迟队列和仿真时钟，支持分段刺激、空白间隔和快照。保证同一输入带分段运行与一次完整运行等价。
2. 冻结原图作为对照；学习状态通过独立权重增量保存，不能污染原复现缓存。将神经记忆与网页聊天历史分开。
3. 审核并选择有明确分区映射的 KC→MBON 已存在突触；仅该局部允许可塑性。使用 DAN 活动调制、含时序依赖的局部规则及有界权重，记录每次更新。
4. 初始学习入口优先考虑文献支持充分的嗅觉—蘑菇体通路；听觉作为后续对照。不能仅凭通路可达就假设能有效驱动学习。
5. 输入 A/B 与结果分别呈现；用未配对、倒序配对和冻结可塑性条件校验规则，然后开展消息学习。

现有社区 dopamine_learning.py 采用人工权重倍乘，不能直接当作经过验证的生物学习模型。奖励与惩罚不能粗略归结为“全部增强/全部减弱”；规则需要结合分区、神经元类型和时序。

## 当前数据核查

FlyWire v783 图中可匹配 KC 5,177、MBON 96、DAN 331 个细胞。全类别并非同一功能分区，也不代表全部都适合作为本阶段学习细胞。

一次粗略的有向图可达性检查：听觉细胞在两跳内可达 7 个 KC，嗅觉细胞在两跳内可达 4,871 个 KC。该检查忽略有效驱动、抑制、连接强度和分区生理，因此只用于决定后续通路检查优先级，不是活动或学习能力证据。

## 验收顺序

1. **动力学一致性**：空白间隔和分段状态正确；关掉可塑性时原模型复现测试继续通过。
2. **已知配对效应**：在所选分区重现文献对应方向和时间依赖，参数范围预先记录。
3. **训练前后差异**：A/B 消息随机分配，结果价值相关的独立测量在训练后改变。预先定义测量，不能看测试结果后挑神经元。
4. **延迟回忆**：结束训练后只呈现消息，不给结果；分别测短暂状态残留与权重变化贡献。
5. **必要性对照**：未配对、打乱配对、关闭可塑性、还原学习权重；效果应相应减弱或消失。
6. **反转学习**：交换 A/B 对应结果，检查神经响应能否随新经验更新。
7. **新试次与扰动**：保留独立随机种子、输入噪声和强度测试；报告效应量及置信区间。成功率暂不预先承诺。
8. **双向表达**：通过上述检验后，才将相应观测翻译成“对这条消息的正向结果预期增加”等有限状态。具体结果身份、空间关系、否定及组合语义各自需要新增任务验证。

同义中文映射到相同码本只证明前端解析一致，不能算作果蝇神经网络理解中文的证据。

## 第一条完整演示的目标

训练：线索 A 后出现正向结果，线索 B 后出现负向结果。

测试：用户发出已支持消息 → 转成 A/B 线索 → 只送入感觉通路 → 等待 → 冻结的测量器判断网络是否出现与已学关联一致的变化 → 输出有证据的语言反馈。

该演示是“学习约定信号与结果的关联”，不是开放自然语言理解。第一阶段不要求命令它转向，也不把运动控制作为唯一接收指标。
