# 感觉 → 模型建议 → 神经回传集成

> 历史实验记录：自动模型建议、回传控制和模型代答已按用户要求从当前应用移除；本地推理服务已停止。当前行为见项目 README 与神经表达模式验收。


2026-09-20，本机真实运行。此轮将已有神经后端、盲读出与听觉命令码本串入聊天界面；没有重新训练神经读出权重。

## 已接入行为

- 人类描述先进入原有感觉解析和连接组仿真；第一条回应只来自本轮内部活动盲读出的白名单标签。
- 默认自动请求已配置 GPT/API。建议请求不含用户原句、输入细胞集合、刺激标签、原始聊天历史或身体运动结果。多份独立神经观测保留各自边界。
- 模型仅返回 `advice` 和 `action`。动作限定 `left/right/forward/stop/none`；无信号、未识别、未达标读出、纯回传命令和冲突感觉只允许 `none`。格式/传输失败保留感觉，不发送替代刺激。
- 合法建议最多回传一次：左右听觉细胞对应左右码字、双侧对应前进、静默对应停止。新的独立神经试次使用新随机种子，固定读出器从内部活动预测码字。
- 聊天界面分别显示感觉、外部模型建议、回传编码和新读出。每次感觉/回传可以单独回放神经活动和身体记录。
- 可选择 GPT/API、本地模型或关闭模型；本地模型配置单独保存，不覆盖远程密钥。
- 普通知识问题仍可自由聊天，本身不运行新刺激。聊天历史属于界面；神经试次之间重置。

## 真实远程测试

使用已配置兼容网关，请求模型名 `gpt-5.5`。该名称属于请求及网关元数据，不是对底层模型身份的独立鉴定。

| 情形 | 本轮结果 |
|---|---|
| 五感组合 | 成功。盲读出五项感觉 → 模型建议向前探索 → 双侧听觉编码 → 新内部活动读出 `forward` |
| 无输入 | 成功。零活动 → 无新感觉 → 模型返回 `none`，未回传 |
| 右前腿触碰 | 感觉读出正确。脚本重试和随后网页实际发送均遇到 55 秒 API 超时，未回传 |

五感真实聊天片段：

> 感觉：我察觉到了光。我尝到了甜味。我闻到了醋相关气味。我感到温暖。我闻到了酵母相关气味。
>
> 模型：可以尝试向前探索当前感知到的光、甜味、醋和酵母相关气味及温暖，但这些感觉未指示具体方向。
>
> 回传：工程码本：双侧听觉细胞 100 Hz 输入。
>
> 新读出：我收到了“向前”的回传信号。

五感建议调用 7.70 秒；无输入调用 50.07 秒。脚本首次触碰请求在本机服务就绪前连接失败，原报告保留；已给脚本加入启动就绪等待。远程结果不可写成全部通过。

原始响应见 `configured/`、`startup-retry/configured/`，完整对话另存于 `reports/dialogue/`，原始脉冲与回传输入事件保留文件哈希。

## 本地模型与完整链路

使用正式提示词与正式请求协议，同样的 24 项边界/感觉案例：

| 指标 | Qwen3 1.7B Q8_0 | Qwen3 4B Instruct-2507 Q8_0 |
|---|---:|---:|
| 结构与动作范围检查 | 19/24 | 21/24 |
| 人工审查无明显语义/策略问题 | 8/24 | 9/24 |
| 典型响应时间（中位） | 0.50 秒 | 0.85 秒 |

人工评审为单次、单审核者的工程判断，不是生物学行为正确率。即使格式合法，仍可能猜测目标位置、误解气味意义，或让建议文字与动作字段不一致。本地模型已经能接入，但不能据此认定自主建议可靠。[逐项评测与来源](../local-model-2026-09-19/README.md)。

另从真实神经仿真开始运行三种输入：

| 输入 | 1.7B | 4B |
|---|---|---|
| 右前腿触碰 | 建议 right，回传新神经活动读出 right | 建议 left，回传新神经活动读出 left |
| 五感组合 | 建议 right，回传新神经活动读出 right | 建议 forward，回传新神经活动读出 forward |
| 空白 | 仍建议动作，校验拒绝并阻止回传 | none，无回传 |

表中方向相符只表示工程码本通信成功，不代表建议本身有生物学依据。4B 的完整链路结构验收 3/3，1.7B 为 2/3。全部原始响应见 `local-4b/local/` 和 `local-1.7b/local/`。两个权重均保留，目前仅 4B 服务在运行；远程配置未改动。

## 解释范围

这是一次通信往返。回传码字被识别不等于身体已经完成相应运动；身体仍由实际运动相关活动驱动。没有身体感觉反馈闭环，也没有证明果蝇拥有语言理解或主观感受。模型结构校验不等于任意自然语言建议的事实正确性证明。
