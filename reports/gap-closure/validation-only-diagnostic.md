# 仅训练/验证缓存的阈值诊断

结论：保留 `alpha=10` 和既有 `0.20–0.80`、步长 `0.01` 的阈值网格。可以将通用选阈规则改为：**先筛选满足现有资格条件的阈值，再在可行阈值中最大化验证 F1；并列时保持最接近 0.5 的规则。没有可行阈值的标签继续不合格。** 这解决了“先最大化 F1，再用另一目标否决”的目标不一致，没有降低精度门槛。

诊断期间未修改生产代码、模型或缓存；两个模型文件前后 SHA-256 相同。只加载 FlyWire 的 272 个训练、94 个验证记录，以及 MaleCNS 的 191 个训练、67 个验证记录。未加载测试、OOD、fresh 神经记录或对应分数，也未打开包含这些成绩的 state-readout 报告。详细 JSON 保留实际加载的 seed 清单。

## 受限参数比较

固定候选只有 `alpha ∈ {0.1, 1, 10}`，特征分别保持 FlyWire 193,482、MaleCNS 242,417 维。采用中心化双空间 Cholesky 解，与带截距岭回归目标相同，没有新增输入标签、入口细胞或其它特征。三个 alpha 在下表所有验证指标上完全一致，因此没有验证证据支持改动 alpha。

| 数据集 | 通用阈值规则 | 合格标签 | 资格过滤后验证 micro-F1 | 资格过滤后验证整组正确率 |
| --- | --- | ---: | ---: | ---: |
| FlyWire | 原网格 F1 最优后审核 | 39/44 | 0.902887 | 0.712766 |
| FlyWire | 原网格中先满足资格再选 F1 | 41/44 | 0.922680 | 0.787234 |
| MaleCNS | 原网格 F1 最优后审核 | 25/28 | 0.933333 | 0.761194 |
| MaleCNS | 原网格中先满足资格再选 F1 | 28/28 | 0.975610 | 0.895522 |

这里的资格条件没有改变：所有孤立阳性验证例都检出；全部验证例（包括阴性、错侧与混合输入）的 precision ≥ 0.90；存在符合公共门槛的内部神经信号。每个待诊断侧标签只有 2 个孤立阳性验证例，分别来自单侧和双侧刺激，因此这些资格结果仍需冻结后的独立种子检验。

## 原不合格标签逐项结果（alpha=10）

TP/FP/FN 指整个验证集；非原不合格标签也采用同一规则检查，没有删去难例。

| 数据集与标签 | 原阈值 | 原 precision | 可行网格阈值 | 新 TP/FP/FN | 结果 |
| --- | ---: | ---: | ---: | --- | --- |
| FlyWire `yeast:left` | 0.33 | 0.7500 | 无 | — | 保持不合格 |
| FlyWire `yeast:right` | 0.50 | 0.7500 | 无 | — | 保持不合格 |
| FlyWire `geosmin:right` | 0.26 | 0.8571 | 0.31 | 4 / 0 / 3 | 满足资格 |
| FlyWire `cva:left` | 0.33 | 0.6667 | 无 | — | 保持不合格 |
| FlyWire `cold:left` | 0.26 | 0.8000 | 0.50 | 3 / 0 / 2 | 满足资格 |
| MaleCNS `foreleg_touch:left` | 0.27 | 0.8571 | 0.42 | 4 / 0 / 2 | 满足资格 |
| MaleCNS `foreleg_touch:right` | 0.30 | 0.8750 | 0.48 | 4 / 0 / 3 | 满足资格 |
| MaleCNS `body_touch:left` | 0.43 | 0.8750 | 0.50 | 5 / 0 / 2 | 满足资格 |

新增合格的 5 个标签，其 precision 均为 1.0，孤立阳性均为 2/2。代价是部分混合输入漏检增加，因此各标签未过滤的 F1 可能下降；表中的总体指标改善来自它们现在能合法输出，而非所有辨别能力都提高了。

同时枚举了验证分数全部断点，分别限制在原 0.20–0.80 范围和不限制范围。FlyWire 的酵母左右与 cVA 左侧在三个 alpha 下仍不存在符合资格的阈值，问题不能只靠换阈值解决。

### 三项保留不合格的不可分理由

以当前 alpha=10 artifact 的验证分数复核：为了保留全部孤立阳性，阈值必须不大于该标签最低的孤立阳性分数。下表的阴性分数仍高于这个上限，因此它们在任何满足孤立召回要求的阈值下都会误报。即使乐观假定检出全部验证阳性，precision 上限仍低于 0.90。

| 标签 | 保留孤立阳性的阈值上限 | 不可避免的阴性验证例（seed：分数） | 全验证阳性数 | 乐观 precision 上限 |
| --- | ---: | --- | ---: | ---: |
| `yeast:left` | 0.438161 | 700227：0.600740；700565：0.874254 | 6 | 6/(6+2) = 0.75 |
| `yeast:right` | 0.504333 | 700557：0.697668 | 3 | 3/(3+1) = 0.75 |
| `cva:left` | 0.577276 | 700568：0.706147 | 4 | 4/(4+1) = 0.80 |

这些误报均包含相反侧的同类输入：例如 seed 700227 仅有右侧酵母，却得到较高的左侧酵母分数；其余为包含相反侧酵母或 cVA 的混合输入。结论限定于当前特征和固定线性分数的验证排序，说明调整统一标量阈值无法同时满足两项既定约束。完整例项保存在 [验证不可分证据](flywire-validation-inseparability.json)；本次附加复核只重新读取 94 个验证缓存，没有新增拟合或扩大搜索。

精确断点搜索对 MaleCNS 右前腿触碰多找回一个混合阳性：阈值约 0.365116 得到 TP/FP/FN = 5/0/2；整体验证 micro-F1 为 0.978723。由于原网格已能满足所有 MaleCNS 标签资格，这个很窄的分隔无需成为本轮增加精细阈值选择的理由；建议保留原网格后开展独立检验。
