# 环境唯一感觉输入修复

2026-09-24，按用户“感觉应该从环境来”的纠正实施。

正常聊天现在为：消息 → 物理呈现 → 实际眼图／感受器位置／碰撞 → 感觉转导 → 连接组活动 → 盲读出文字及神经驱动身体。聊天翻译不再产生一条独立神经刺激磁带。服务端和具身入口双重拒绝 `environment_only` 模式下的直接输入；旧 `/api/receive` 也进入同一路径。直接神经干预留在明确标记的独立实验中，不共享聊天会话。

## 实现

- `environment_message.py`：简单物品语句变为可应用的真实场景对象；默认指定方位 3 mm，未指定则前方。物品进入实际碰撞和官方双眼渲染。应用成功后记录“环境改动”；按已有规则，持久几何变更明确重新初始化会话。
- `physical_touch.py`：六个预编译的 MuJoCo mocap 球形探针，半径 0.06 mm。方向语句呈现对侧前腿探针，前进与退出各 50 ms。目标在呈现开始时从实际身体姿态定位，随后轨迹固定，不追踪身体。强度改变有限物理压入量，不直接改变神经事件率；未做力学／生理校准。
- `sample_environment` 继续按实际碰撞到的腿决定接收侧别和部位。没有采样到碰撞就没有该触觉输入。探针参与官方眼图，并在身体回放中显示实际位置。
- `run_embodied` 的正常聊天模式只编码每 100 ms 的环境采样。膜电位、延迟队列、身体和控制器跨消息保留。新增探针不重建身体或神经状态。输出仍排除感觉及直接输入细胞，不接受消息意图作为读出答案。
- 暂无环境物理呈现的通道明确返回未实现，不能偷偷使用旧直接神经刺激。

## 实测

`acceptance.json` 是三个真实 MaleCNS + MuJoCo 500 ms 对照，每条包含 5 次感觉采样：

| 场景 | 结果 |
|---|---|
| 空环境、无触碰 | 0 个感觉事件，0 次记录脉冲 |
| 右前腿物理探针 | 0 ms 无触觉；100 ms 实测探针碰到右前足，随后 235 个感觉事件；共记录 3588 次脉冲（包含所有记录细胞，非仅内部细胞） |
| 右侧远糖、未接触 | 无味觉输入；MaleCNS 感觉事件为 0。视觉由独立 FlyWire 通路测试，不能把本项解释成看不见 |

三条无 MuJoCo 数值警告，全部与已保存感觉磁带的神经重放逐项一致。上述触碰结果只证明物理接触能进入神经通路，不能证明逃避或执行转向。

`chat-acceptance.json` 使用真实 `Application.converse` 连续发送三条消息；每条分别运行 FlyWire 和 MaleCNS，测试场景在内存中发布，保存的用户环境文件哈希保持一致：

1. “右边有糖”：右侧约 3 mm 加入糖并发布环境事件。FlyWire 从眼图产生 23914 个视觉事件；MaleCNS 无味觉输入。聊天只有候选明亮读出，没有“尝到糖”。
2. “左转”：同一会话 500–1000 ms 呈现右前腿探针；MaleCNS 实测接触后产生 233 个触觉事件，聊天为候选“我感到右前腿被碰到了”。神经与身体重置次数均为 0。
3. “看看环境”：1000–1500 ms 继续同一状态，探针退出后 MaleCNS 本窗口无新触觉输入；仍无味觉。神经与身体重置次数均为 0。

回归测试：新增环境消息与既有场景／会话／神经因果性／运动适配／身体物理／读出等共 199 项通过。页面另从正常聊天发送“左转”，显示“用真实碰撞探针尝试触碰右前腿；实测到探针与腿接触”，并显示对应候选神经读出，页面控制台无错误。

最终版本又从页面发送“右转”，默认展示 MaleCNS。该次左前腿探针未在感觉采样时测到接触，因此 MaleCNS 0 个输入事件、0 次脉冲，不生成触碰句子；FlyWire 仅有环境光照候选读出。页面在 100 ms 回放实际探针，控制台无错误。用户场景仍为第 5 版、8 件物品。此负例保存在 `browser-acceptance.json`；未为了让方向指令“成功”而补发神经输入或身体命令。

## 保留限制

物理环境是真正输入来源，但感觉转导仍有工程假设。视觉仍为分眼亮度，未完成小眼到连接组列的配准；腿味觉仍是群体候选，高盐腿部映射缺失；每 100 ms 的采样可能漏掉更短暂接触；物理探针的力与神经反应未做生物学校准。声音、cVA 等没有物理环境呈现的旧神经实验通道不会进入正常聊天。有限标签读出不能等同任意语言理解，探针位移与被推动也不能等同自主逃避。

复验脚本：`scripts/check_environment_input.py`、`scripts/check_environment_chat.py`。
