# 第二只果蝇：同种信号闭环

`scripts/conspecific_loop.py` 把"果蝇之间怎么沟通"接成一个最小的双个体闭环，用两个**独立的** MaleCNS 会话：

```
A 的记录运动活动（song 组 > 0）
        ↓ 声明的工程约定（不是解码出的"歌"）
在 B 的实际 pedicel 位置放 song 工程场
        ↓ 物理采样（每 10 ms，实测场强决定是否产生事件）
B 的听觉入口事件 → B 的盲读出 → B 的实测身体结果
```

## 运行

```powershell
.venv\Scripts\python.exe -X utf8 scripts\conspecific_loop.py --fly-a-windows 6
```

输出：`reports/conspecific-loop/latest.json`（每次运行的完整阶段记录），逐窗原始记录在 `data/derived/conspecific-loop/`。

## 每一步都只允许用实测的东西

| 环节 | 依据 | 不允许 |
|---|---|---|
| A 是否"唱歌" | A 的**记录运动活动**里 `song` 组在该窗内的实测最大值 | 用人类消息、场景物品或"想让它唱"来决定 |
| 信号传递 | 在 B 的实际 `l_pedicel` 位置放非实体工程场，B 侧**实测**场强 | 直接把事件注入 B 的听觉细胞 |
| B 的回应 | B 的盲读出（排除全部感觉与输入细胞）+ B 的实测身体结果 | 把 A 的信号当作 B 的意图，或让读出抄回输入 |

## 明确不作声明的事

- A 的 `song` 运动组 > 0 **不等于**它在"唱歌求偶"：那是固定工程控制器在该窗输出的一组运动指令。
- 场到 pedicel 的映射是**工程约定**：不是解码出的声学信号，也没有声压、载波、相位与传播模型。
- B 的读出只说明"听觉入口收到事件后内部活动能读出什么"，不说明它"听懂了 A 的意思"。
- **A 若在采样窗内没有唱歌，脚本如实报告"未产生同种信号"**——没有回应也是结果。

## 与个体规则的相容性

- 两个会话各自是**同一个 MaleCNS 个体**的两份独立运行，不把它们拼成一个"群体神经网"，也不混合 ID 命名空间。
- 这与契约允许的"独立实验"一致；本脚本不进聊天通路，也不改变正常聊天会话的状态。
