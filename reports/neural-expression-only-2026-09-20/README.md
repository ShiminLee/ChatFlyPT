# 移除外部模型控制，恢复神经读出表达

2026-09-20，按用户明确要求纠正前一轮实现。此前将 GPT/Qwen 的行动建议编码回听觉神经，是额外的外部控制，不符合让模拟果蝇自身神经活动决定表达和动作的要求。

## 当前通路

明确感觉输入 → 连接组仿真 → 内部活动盲读出 → 感觉文字。

身体分支：本次真实神经脉冲 → 原有运动相关细胞群读出 → Bad Apple Fly / NeuroMechFly 控制器 → 实际身体轨迹。

GPT/Qwen 不参与以上两条通路。提问只读取当前选中神经记录，不调用模型代答，也不会启动新的刺激。

## 已移除的入口

- 自动模型建议与神经回传；`Application.feedback` 明确拒绝调用。
- 对话模型选择、建议回传开关；旧浏览器的 `backend=local/configured`、`feedback_enabled=true` 也无法重新启用它们。
- 注意：曾误将人的“左转/右转”翻译层一起删除，用户澄清后已恢复。人类方向表达 → 对侧触碰属于必要感觉编码；只有模型自行给建议并回灌的路径被移除。
- 大模型自由聊天代替果蝇回复。当前感觉文字由盲读出标签直接表达。
- 原来自动附加的“我该怎么办”提问尾句。

用户使用人类语言；触碰/气味/声音等感觉方案是内部译码结果，也可从实验面板检查。本地 Qwen 推理进程已停止；权重与加密 API 配置保留，历史实验报告标注为已撤下的旧方案。

## 验证

- 195 项组件及输入解析测试通过，包含即使旧参数开启模型/回传也不调用模型、不回传的回归。
- 25 项真实连接组通路回归通过。以上合计 220 项，不是全仓库测试。
- 前端 JavaScript 语法检查通过。
- 真实 HTTP：右前腿触碰、五感组合、空白试次全部通过。每个输入只有起始神经记录和感觉消息，没有模型请求、建议或回传观测；追问仅读取选中记录。
- 人的“左转”通过 `/api/communicate` 翻译为右前腿触碰并产生一份神经记录；中间框显示译码，模型建议回传仍不可启用。修正后 127 项相关回归通过，见 `translation-correction-tests.xml`。
- 右前腿和五感两项使用相同种子，与之前保存的起始记录逐数组比较：脉冲计数、脉冲细胞、时间步和直接输入细胞全部一致；身体控制数值摘要也一致。移除的是外加干预，没有更换神经反应或伪造动作。
- 实测右前腿输入未产生当前控制器可用的动作；五感输入产生实际身体仿真轨迹；空白没有动作。没有为满足“应当动”而补写动作。

原始 HTTP 数据与验收见本目录 `acceptance.json`、三个案例 JSON；回归结果见两个 XML。重跑：

```powershell
.\.venv\Scripts\python.exe -X utf8 scripts/verify-neural-only.py
```

## 仍然存在的边界

目前的文字表达仍依赖已验证的感觉标签，不能解释为任意“思想”的开放翻译。神经试次之间独立重置；身体仍由现有功能读出与物理控制器执行，没有连续身体感觉反馈闭环。去掉大模型控制不等于已经完成自主生命体仿真。
