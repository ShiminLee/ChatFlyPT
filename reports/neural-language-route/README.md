# ChatFlyPT 神经读出语言通路验收

2026-09-24。依据用户最新要求，恢复 chetaslua 公开展示的路线：人的消息 → 感觉编码 → 连接组内部活动 → 盲读出标签 → 聊天中的自然语言。运动相关活动独立进入现有物理控制器。没有接回 LLM 建议，也不要求先产生物理声波或化学信号。

这次修复的是聊天表达分支：之前 `expression.py` 始终返回 `decoder_unavailable`，即使感觉盲读出已有结果，聊天仍为空。现在聊天显示“果蝇 · 神经读出”，接收框保留输入翻译、细胞与感觉证据；不同连接组分别显示。无活动、未知标签、入口未校准、冲突标签及仅有历史回传命令时保留系统状态，不伪造果蝇回复。问句读取旧记录时明确标注“上次记录”，不当成新神经仿真。

## 公开示例的新仿真

运行 `scripts/verify_neural_language_route.py`：20 个预先固定的新随机种子 2026092400–2026092419，各运行 300 ms，输入展示组合“醋、酵母、糖、温暖、明亮”。读出器只读取内部神经计数，所有感觉细胞和直接输入细胞均排除在读出特征之外。

- 20/20 新试次恢复全部五个标签，并由当前聊天表达器生成中文。
- 另对原有 20 份神经存档重新读出：20/20，原始文件哈希全部一致。
- 单独运行无输入对照：没有果蝇聊天消息。
- 没有添加固定的“我该怎么办”作为解码出的意图；没有调用 LLM、导航策略或发声合成。
- 实际中文：我察觉到了光。我尝到了甜味。我闻到了醋相关气味。我感到温暖。我闻到了酵母相关气味。
- 数值结果、模型与代码哈希、每个新试次的原始记录路径见 [acceptance.json](acceptance.json)。这个脚本验证的是独立神经试次，不包含持续环境校准或身体物理验收。

## 软件测试

150 项通过：46 项表达、对话/API、无模型回传、声学隔离及推理依赖测试；25 项使用真实连接组和读出器的通路测试；79 项场景和输入语言测试。JavaScript 语法检查通过。通路测试从保存的脉冲流重建计数，再重新解码并生成聊天文字，核对其与运行时输出一致；同时验证改变感觉/直接输入细胞计数不能改变盲读出。

## 范围

这是根据公开描述的独立功能重建。没有取得作者完整源码、权重和全部实验协议，不能称为精确复制。连续环境中的预测保留“候选神经读出（连续反馈尚未校准）”，本次 20/20 不能外推到这些试次。词汇、输入语义和感觉映射有边界，不能声称任意自由聊天或真实果蝇语言已经破译。

浏览器会话继续保留各连接组的神经/身体动态状态，100 ms 感觉反馈，等候消息时暂停。环境改动、新对话及服务重启会初始化状态；独立实验保持重置。此次服务更新发生了一次重启，已应用场景仍为第 5 版、8 个物品。
