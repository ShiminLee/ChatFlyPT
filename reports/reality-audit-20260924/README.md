# 按真实情况复核：完成边界与已知反例

复核日期：2026-09-24。结论：**有限场景的环境—神经—文字／身体—环境反馈链路已运行；完整单个果蝇的多感觉整合、真实行为还原与开放自由聊天未完成。** 不能用真实连接组、真实物理引擎、接口成功或回归测试数量替代这些完成标准。

## 实际运行的链路

人的消息 → 物理物品／场／碰撞探针 → 实际眼图、感受器位置和接触采样 → 感觉转导事件 → 连接组模型 → 两个分支：盲读出有限内部状态标签并组成句子；运动相关活动经控制器驱动身体。每 100 ms 继续采样同一身体和神经状态。主通路没有 LLM 行动建议或意图到动作的直接赋值。

这条结构在各自支持的场景中已运行，**但 FlyWire 与 MaleCNS 仍各用独立神经状态和独立身体**。视觉、嗅觉主要落在 FlyWire，腿触觉／味觉主要落在 MaleCNS；不能将两个模型的结果拼成同一只果蝇“看见—走近—尝到”的完成证据。

环境唯一输入修复后的真实证据见 `../environment-only-20260924/README.md`、`acceptance.json` 和 `chat-acceptance.json`。这些记录包括远糖没有误成味觉、探针实际碰到右前腿后才产生输入、探针未接触时保留无响应。口器糖／盐、热源反例见 `../sugar-pressure-20260924/README.md`；该批历史实验中的“人类消息糖”和“强触碰”组当时使用直接神经输入，只能作为神经／运动层诊断，不能算新的环境输入路径验收。

## 各部分真实性

| 部分 | 已实现／已有证据 | 尚未还原的部分 |
|---|---|---|
| 物理环境 | 应用后的糖、盐、酵母、方块进入实际碰撞和官方双眼渲染；草稿不生效 | 化学释放、热交换与受体转导不等于真实材料；新增／移动持久物品会重置神经和身体 |
| 视觉 | 保存每眼 721 小眼；实际画面进入分眼亮度通道 | 小眼到连接组列的空间配准未完成；不能认出糖或读出糖的位置；看到糖实体不等于尝到糖 |
| 嗅觉 | 酵母的工程距离场在实际触角位置采样，使用 DM2 代理入口 | 没有真实气流／气味羽流、混合组分及浓度响应标定；并非所有气味通道都有环境呈现 |
| 温度 | 热／冷工程场按实际感受器位置采样 | 参数不是摄氏度，缺少热传递／动态受体标定；热源测试有不存在酵母或蒸发冷却的误报，酵母适配器已停用 |
| 口器糖 | 实际口器接触后出现候选甜味读出和实测喙伸展姿态 | 未模拟真实摄食量、营养吸收、饥饿／饱腹；口器几何接触不能替代逐感器模型 |
| 腿部糖 | 实际腿接触选择相应侧别／腿别的候选入口；神经活动可进入部分关节控制 | 仍是 LgLG4/LgAG2 群体候选，无合格的新入口语义读出；没有证明寻糖、停留或摄食序列 |
| 高盐 | 口器接触与神经读出可运行 | 当前口器盐会驱动更强进食姿态，未形成验证过的回避；LB3d 身份／递质冲突待解决；腿部高盐入口仍缺 |
| 机械触碰 | 物理探针、腿几何碰撞、侧别和触觉事件已接入 | 不同触毛的偏转、力—放电关系、全身接触入口和快速感觉时序未校准；未证明侧向触碰必然转向或逃避 |
| 本体感觉 | 身体引擎测得关节和足部状态，Hybrid 控制器使用部分反馈 | 关节角度／速度／负荷到连接组本体感觉入口未形成完整通路；地面负荷不能因控制器已使用而算回到了脑内 |
| 声、风、湿度、CO₂、社会化学等 | 部分已有注释和独立神经实验通道 | 正常环境没有完整物理呈现／受体采样；不能用直接注入补齐后宣称自然感知完成 |
| 运动 | 复用固定版本控制器；13 组行为控制与 96 个精确胫节运动细胞到六腿关节的部分映射；真实 MuJoCo 轨迹 | 尚非全部肌肉／关节的生物学校准；姿态维持、被探针推移、重力位移不等于自主运动；强触碰与高盐反例未解决 |
| 语言 | 推理仅用排除感觉／直接输入细胞后的内部记录，有限标签变成忠实句子；保留无响应 | 有限候选感觉句不是任意问题理解、意图或开放语义；持续反馈新分布仍有误报；不是作者原始源码与权重的精确复制 |
| 持续状态 | 同一浏览器会话中普通消息之间保留神经／身体状态 | 等待消息时暂停；环境几何变更、新对话、服务重启会初始化；60 秒上限；没有长期学习或已校准的内稳态 |

## 数据已经有的部分与模型仍缺的部分

直接读取本地官方 MaleCNS 注释，筛选 `superclass` 含 `sensory` 并按精确 `class` 统计：

| 注释类别 | 细胞数 |
|---|---:|
| visual | 6,091 |
| olfactory | 2,639 |
| thermosensory | 25 |
| mechanosensory_proprioceptive | 1,454 |

完整类型、侧别计数和源文件哈希保存在 `malecns-inventory.json`。这些是候选整合材料，不是已校准通道或所有出边可用的保证；例如 411 个嗅觉细胞缺少左右入口标签。需要核对入口、实际图中出边、空间对应及响应规律，随后在同一 MaleCNS 神经—身体模型内接入并独立验证，不能把 FlyWire 的 ID 或旧读出权重直接移植。

当前 MaleCNS 模型纳入 166,700 个有 superclass 注释的细胞，24,559,135 条建模边；另有 1,023,803 条边没有快速递质模型，未知及单胺类传出效应为零。神经动力学使用统一的 Shiu 风格 LIF 参数，0.1 ms 步长、1.8 ms 延迟及 0.275 mV/突触增益，没有完成 MaleCNS／腹神经索的生理校准。数据来源是实际连接组，**并不意味着当前动力学已经等同活体果蝇大脑**。出处为 `data/derived/malecns/graph.json`，副本纳入本次清单。

## 本次修复与验证

`chatflypt/environment.py::measure_environment_contacts` 原来把 MuJoCo 接触列表中包含的近距离记录也当作实际物品接触。现在要求：激活的约束、几何表面距离 ≤ 0、另一端为果蝇身体；并记录法向／切向接触力及 `force_calibrated: false`。没有引入任意的力到神经放电系数。

新增 `tests/test_contact_physics.py` 使用实际 MuJoCo 3.9.0 验证三种情况，记录见 `contact-physics.json`：

| 几何表面距离 | MuJoCo 记录 | 是否作为感觉接触 |
|---|---|---|
| +0.25 模型长度单位 | gap 范围内，约束未激活 | 否 |
| +0.05 模型长度单位 | margin 内，约束已激活但表面仍分离 | 否 |
| −0.05 模型长度单位 | 实际表面重叠，约束已激活 | 是，保存接触力但不称其已校准 |

本次联合回归包括 `test_contact_physics.py`、`test_environment.py`、`test_environment_message.py`、`test_scene_language.py`、`test_conversation.py`、`test_embodied_physics.py`。70 项既有检查通过；新增测试的第一版夹具误用了旧版本 margin/gap 预期，调整分离距离后独立重跑通过 1 项。合计 71 项已验证通过。真实 300 ms MaleCNS + MuJoCo 糖平台测试在新接触过滤下仍有腿糖输入，且事件磁带重放与累计计数、脉冲时间和状态逐项相同。

这些验证只证明修复后的实现满足相应软件／物理判定约束，不证明行为真实性。此轮没有重跑所有历史行为试次，也没有将历史直接刺激结果改写成自然环境结果。

## 后续完成顺序与可验收标准

1. 用已有 MaleCNS 材料接入同一模型的视觉、嗅觉、温度等入口，完成身份／侧别／出边和独立读出验证。先验证统一通路，之后才评估多感觉整合能力；不得把两个独立身体拼接成完成证据。
2. 接入关节角度、速度、负荷等实际身体反馈，并改造场景更新以保留同一个体状态；按实际瞬时接触采样，验证不会丢失关键感觉事件。
3. 分别修补小眼空间对应、受体及转导模型、未映射运动执行；使用环境呈现后的对照行为验证，不从目标答案直接赋予运动。
4. 用糖接触／撤除、不同盐浓度、不同位置与强度触碰、热冷梯度、视觉／气味冲突等对照，分层核对实际感受、内部响应、神经驱动行为和盲读出。候选通道未通过时保留失败，不能训练一句预期文字掩盖错误行为。

## 本次核查的一手资料

- [NeuroMechFly v2（Nature Methods, 2024）](https://www.nature.com/articles/s41592-024-02497-y) 和 [作者 FlyGym 源码](https://github.com/NeLy-EPFL/flygym/)：提供具身感觉运动研究框架；具体感知、反馈与控制器仍须接入和验证。使用该物理身体不是获得了完整大脑控制器。
- [DeAngelis 等（eLife, 2020）](https://elifesciences.org/articles/54183)：在行走果蝇上做精确感觉细胞光遗传刺激，观察到刺激类型相关的转向。该实验证据不能直接证明我们未标定的机械探针参数必然产生同样动作，更不证明果蝇理解“左转”中文。
- [Distributed control circuits across a brain-and-cord connectome（Nature, 2026）](https://www.nature.com/articles/s41586-026-10735-w)：脑和腹神经索的分布式控制、局部与长程回路为整合提供结构依据；连接图本身不规定全部动态参数。
- [Ascending neurons convey behavioral state to integrative sensory and action selection brain regions（Nature Neuroscience, 2023）](https://www.nature.com/articles/s41593-023-01281-z)：支持身体状态反馈需明确进入神经通路，而非把局部控制器反馈等同于大脑接收。
- [MuJoCo 碰撞与接触官方说明](https://mujoco.readthedocs.io/en/latest/computation/)：接触列表可包含非激活及 margin 范围记录。此修复以本机 3.9.0 的实际接触距离、约束地址和力验证为准。
