## 为什么不能将高分当作完整感知

本批次使用旧的 bounding-box 候选视网膜几何，随后找到作者的实际光轴数据。该投影将被新的几何版本替换，本批次只作基线，不能把这些权重直接用于新图。此外，审计发现旧身体 API 对一个不存在的眼 body ID 使用了 `-1` 索引；当前正在改为真实眼相机位置，不能将旧单眼位置用于空间设计。

最重要的实验混淆是：中／后腿触碰、腿部局部甜味和上行适口味觉在本批次始终共同出现于糖平台。盲特征不等于已经排除了这个物理实验混淆。分类器可能借用了伴随接触或视觉关联，所以不能把它报告为已经分别分辨这些感觉。下一批次预注册相同几何普通平台、远糖及暗中糖／普通平台，并尝试固定单侧呈现；只有实际投递才构成正例。

本报告不是自然果蝇感知准确率，不证明人体语言理解、物体识别、定位、意图、自由聊天或动作的生理真实性。未发布默认权重。
