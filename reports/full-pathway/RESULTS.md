# ChatFlyPT 完整通路验证

日期：2026-09-19。本文记录本地实际运行结果，属于独立实现，不是 chetaslua 未公开的源码或权重。

后续已新增 API 设置并完成真实网关请求；当前网关存在间歇 HTTP 502，真实演示验收为部分完成。最新 API 状态见 [配置与请求验证](../api-settings/RESULTS.md)。本文的 80 项测试是接入设置功能之前的运行；新增设置后全量为 94 项通过。

当前软件通路为：**支持的文字输入 → 感觉事件 → 对应连接组仿真 → 内部脉冲计数的盲读出 → 中文回应**。输入说明、神经活动、读出标签和中文回应可在同一次请求中返回。这里验证的是预先定义的感觉输入及其模型响应，不表示果蝇已经理解人类语义。

## 通路与数据集

| 输入 | 仿真数据集 | 读出目标 |
| --- | --- | --- |
| 左前腿／右前腿触碰 | MaleCNS v1.0，脑与腹神经索 | 左触碰、右触碰；训练另含双侧及空白 |
| cVA 信息素／求偶脉冲声 | FlyWire v783 脑连接组 | cVA、求偶脉冲声、空白 |
| 原有 16 种感觉代理 | 原有 FlyWire v783 后端 | 原有感觉词表 |

两个连接组使用不同细胞 ID 空间，不把 MaleCNS 的腿部细胞直接注入 FlyWire。左右触碰分别使用 124、100 个前腿触毛候选感觉细胞；这些尚未精确缩小到原触碰实验的腿末端感器群。刺激时间包络及脉冲强度仍为工程设定。

文字解析仅执行已支持且明确的感觉描述。“向左／向右”编码为对侧前腿触碰时，会标记为待验证的提示方案，不把方向词当成已发生的转向。读出器只接收模拟得到的神经脉冲计数；中文回应仅依据读出标签与测得的内部活动，不用原输入标签代填结果。

cVA 与求偶脉冲声已有专门的 500 ms 读出训练，不再借用原 16 词中不同刺激协议的权重。当前界面分别执行这两个通道，训练没有测试二者同时输入。触碰训练中的“双侧”用于评估读出能力，不代表界面已支持任意混合或多步指令。

## MaleCNS 图与模型假设

从官方原始 151,856,684 条连接记录中，保留两端均有非空 `superclass` 注释的 166,700 个神经元；未分类碎片被排除。保留范围内有 25,582,938 条连接记录、124,177,617 个连接权重总量；在快突触符号模型下，实际传播图包含 24,559,135 条边。

突触符号按 `consensus_nt` 分配：乙酰胆碱为正；GABA、谷氨酸、组胺为负。该统一符号处理是模型简化。未知递质及多巴胺、章鱼胺、血清素等单胺的出边没有快突触模型，对应 1,023,803 条连接不参与传播；不能将其理解为这些递质在真实果蝇中没有作用。

动力学移植本项目已有的 Shiu 风格 LIF：步长 0.1 ms，静息电位 −52 mV，阈值 −45 mV，膜时间常数 20 ms，突触衰减 5 ms，传递延迟 1.8 ms，不应期 2.2 ms，每连接权重增益 0.275 mV。直接刺激细胞的输入处理沿用原引擎。每个试次从静息状态重新开始，没有连接组内学习或跨轮神经记忆。这些参数尚未针对 MaleCNS／腹神经索进行生理标定。

图的源文件哈希、输出哈希和完整统计保存在 [graph.json](D:/Projects/python/fly/reports/full-pathway/graph.json)。数据和模型来源分别为 [MaleCNS 官方下载](https://male-cns.janelia.org/download/) 与 [Shiu 等的计算模型论文](https://www.nature.com/articles/s41586-024-07763-9)。生物学映射的证据与限制见 [输入核查报告](D:/Projects/python/fly/research/biological-input-audit.md)。

## 固定协议和结果

所有刺激条件、种子、强度和数据划分均在执行对应实验前由代码固定。训练只使用训练集的活跃特征，阈值只依据验证集选择。两个读出器均使用内部脉冲计数的平方根特征和 `Ridge(alpha=10)`；分数没有校准为概率。下表的准确率要求预测标签集合完全匹配，包含空白试次。

### 左右前腿触碰

每个试次 500 ms，条件为右侧、左侧、双侧、空白。排除所有 17,937 个感觉类细胞及 224 个直接刺激细胞，最终选出 4,626 个训练期活跃的内部细胞。强度随机数种子为 `2026091902`；右侧用试次种子编码，左侧另加 `1000000`，使两侧事件独立。

| 划分 | 每条件次数 | 基础试次种子 | 强度倍率 | 完全正确 |
| --- | ---: | --- | --- | ---: |
| 训练 | 16 | 130000–130063 | 0.85–1.15 | 64/64 |
| 验证 | 6 | 140064–140087 | 0.85–1.15 | 24/24 |
| 测试 | 10 | 150088–150127 | 0.85–1.15 | **39/40，97.5%** |
| 强度外推测试 | 8 | 160128–160159 | 0.6、1.4 | **26/32，81.25%** |

普通测试 micro-F1 为 0.98765，强度外推为 0.89655。普通测试有一次左触碰被额外识别成右触碰；外推测试的六次错误均发生在 0.6 倍弱输入，表现为漏检。全部错误、分数、原始计数文件及各神经类别的活动汇总已保留，未据此重新调阈值。

负对照使用同一个已经拟合的读出器：

| 对照 | 结果 | 含义 |
| --- | --- | --- |
| 打乱测试神经观测，种子 982 | 8/40，20%；micro-F1 0.54321 | 破坏输入与标签配对后明显下降 |
| 将全部测试观测替换为零 | 10/40，25%；micro-F1 0 | 全部判为空白；正确项就是十个空白试次 |
| 删除全部 224 个输入细胞的 15,267 条建模出边 | 右侧内部脉冲 3,974→0；左侧 611→0 | 直接输入仍存在，内部传播与对应读出消失 |

全图断边对照基础种子为右侧 `170000`、左侧 `170001`。完整图分别读出相应侧触碰；断边图均返回空标签。小图测试另核查了延迟传播、断边效应和 ID 空间隔离。

完整记录：[touch-protocol.json](D:/Projects/python/fly/reports/full-pathway/touch-protocol.json)、[touch-readout.json](D:/Projects/python/fly/reports/full-pathway/touch-readout.json)。权重位于 `data/derived/malecns/touch-decoder.npz`，原始计数及神经元顺序见报告内路径。

### cVA 与求偶脉冲声

固定协议包含空白、cVA、求偶脉冲声三种条件，每次 500 ms。训练 48 次，验证 18 次，测试 30 次；排除感觉类及直接输入细胞，最终保留 8,248 个训练期活跃的内部细胞。强度随机数种子为 `150000`。

| 划分 | 每条件次数 | 试次种子 | 强度倍率 |
| --- | ---: | --- | --- |
| 训练 | 16 | 150000–150047 | 0.85–1.15 |
| 验证 | 6 | 150048–150065 | 0.85–1.15 |
| 测试 | 10 | 150066–150095 | 0.75、1.0、1.25 |

测试 **30/30，100%**，micro-F1 为 1.0；其中十个为空白。打乱观测（种子 `15`）后为 13/30、micro-F1 0.45；零观测为 10/30、micro-F1 0。此组未执行独立的全图断边实验，也未测试两个社会通道的混合输入。

完整记录：[social-readout-protocol.json](D:/Projects/python/fly/reports/full-pathway/social-readout-protocol.json)、[social-readout.json](D:/Projects/python/fly/reports/full-pathway/social-readout.json)。权重位于 `data/derived/social-input/social-decoder.npz`，计数位于同目录 `social-counts.npz`。

## 自然语言、界面与复现

全量自动测试 **80 项通过，0 跳过，26.67 秒**，记录见 [pytest.xml](D:/Projects/python/fly/reports/full-pathway/pytest.xml)。其中 16 项新增集成测试使用六个新种子 `2026091901–2026091906`，实际运行左右触碰、cVA、鸣声、五感和空白；保存的脉冲事件能重建计数、再次解码、计算反应汇总，并得到相同中文回应。测试还确认感觉细胞计数扰动不影响读出，否定/未知文本不启动仿真，mock ChatGPT 只接收白名单神经证据。这些是通路正确性测试，不把六次新试验另报为统计准确率。

模型现在能通过中文句子表达“读出了右前腿触碰”和“记录到了内部活动”等结果。表达使用可审计的规则模板；无需 API 密钥即可走完支持输入的神经仿真通路。真实 ChatGPT 自由对话是独立可选功能，取决于本机 `OPENAI_API_KEY` 与 `CHATFLYPT_MODEL` 等配置是否有效，不能将模板输出记作已经调用 ChatGPT。自由对话也不自动构成新的神经刺激。

已记录运动相关输出细胞的脉冲，但未接入身体物理仿真；没有经过验证的行走轨迹或左转／右转动作。“内部活动→标签”的结果也不能支持额外声称情绪、意图、拒绝、意识或自然语言理解。当前验证的是软件中的限定通路，尚无真实果蝇实验、随机连接基线或优于其他模型的结论。

运行 [reproduce-pathway.ps1](D:/Projects/python/fly/scripts/reproduce-pathway.ps1) 会先检查本项目 `.venv`、本地连接组和已经准备好的 16 词模型，再依次生成感觉目录、构建 MaleCNS 图、训练触碰读出、训练社会信号读出、执行测试。脚本不下载数据、不安装依赖、不调用外部大模型；`-CheckOnly` 可只检查准备情况。命令：

```powershell
.\scripts\reproduce-pathway.ps1 -CheckOnly
.\scripts\reproduce-pathway.ps1 -Workers 4
```

此脚本会更新训练产物与 JSON 结果。上文数值对应本次报告保存的结果；后续若改变协议或代码，应以重新生成的 JSON 和测试输出为准。原 16 词及作者展示例子的独立复现结果仍见 [原实验报告](D:/Projects/python/fly/reports/reconstruction/RESULTS.md)。
