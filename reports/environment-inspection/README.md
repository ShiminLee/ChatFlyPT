## 记录解释

原固定姿态预热 50 ms 内有执行器输出；其后的记录窗口关闭全部执行器，运动来自重力、被动关节、碰撞及显式系留约束，不代表自主回应。接触为 20 ms 间隔采样，可能遗漏瞬时接触；0 ms 的“接触开始”只表示首次观测已接触。双眼图每次只保存三时刻，不是连续视频。热/冷/气味仍是工程场定义，不能把形状或颜色当成化学识别。

旧物理调试记录中不带 `inspection_full_body_ground_contacts` 的文件使用修复前配置；本报告和当前页面引用的是修复后的记录。`reports/environment/` 仍是旧神经试次记录，不与本轮物理验收混用。

接收感觉继续放在接收框；聊天只允许有证据的对外表达。对外沟通的语义解码、视觉空间配准、腿部味觉桥接和持续反馈没有在本轮实现。
