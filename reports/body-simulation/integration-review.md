原始 NPZ 校验和与返回值相同。独立从其逐脉冲记录、注释和直接刺激细胞重建驱动后，来源 SHA-256、运动细胞计数与身体结果一致。两次独立试次 ID 不同，在同 seed 下产生相同神经数组与完全相同的物理轨迹。HTTP 中的轨迹也与该 ID 对应的 `body-trials/body-result.json` 逐帧相同。每帧位置、六足、四元数、66 个关节角均为有限数值，时间严格递增。

第一请求曾在客户端等待 180 秒后超时；服务端稍后完成并保存为 `fc81ab59b874442fbb12d1f30dd71ea1`，该次观察内部计时 146.40 秒、身体部分 19.05 秒。前置加载/等待不完全包含在观察计时内。只有确认首请求已结束后才进行第二次请求；上述 HTTP 200 来自第二次完整响应。首次超时记录保留，不计作成功 HTTP 返回。并行训练期间存在明显性能波动。

程序层绘图复核执行了生产代码中的 `drawPhysicalWorld`，以真实 HTTP 返回作为输入。在 640×230 与 290×180 两种画布、0/70/250/500 ms 共八种情况下：六个绘制足端逐一等于返回坐标的投影；朝向等于实际 `yaw_rad` 的屏幕转换；选择的帧与物理时间一致；坐标均有限且在画布内。该检查使用记录调用的 Canvas 桩，**不是浏览器视觉或布局验收**。身体连接线明确为示意，未发现用周期函数伪造足端摆动。前端截断后停留在最后的实测帧，没有循环延长动作。
