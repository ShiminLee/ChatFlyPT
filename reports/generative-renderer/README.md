# 接地生成式渲染器（组合句子，不是模板）

这一层回答"生成式"那一步：让果蝇的话**能被组合**，而不是从 18 个固定句子里挑一个。**每个内容槽都来自盲读出**，渲染器只决定怎么说，不能增加事实。

## 槽位与来源

| 槽位 | 来源 | 合格情况（conspecific-v5） |
|---|---|---|
| 通道 × 侧别 | 已发布的统一盲读出（`unified_readout`） | 18/30 合格，含光、触碰、腿部味觉、cVA、鸣声 |
| `activity:quiet/moderate/busy` | 新增槽位读出（`slot_readout`）：窗口内**非感觉非输入**脉冲数，训练集 33/66 分位为界 | 三档全部合格；测试 micro-F1 0.888 |
| `pattern:sustained/transient` | 同上：窗口内**实测投递样本占比**，阈值 0.3 | 只有 `sustained` 合格（`transient` 验证正例仅 2 个）。本语料里 `sustained` 近乎恒定（96/98），因此它更像"有持续感觉"的总括，不是真正的对比 |

三个槽位家族都走同一套纪律：同一盲掩码（排除全部感觉与已注册输入细胞）、阈值只取训练集、逐标签资格（≥2 正 2 负、precision ≥ 0.9、recall ≥ 0.75）、不合格即弃权。

## 渲染规则

- 顺序：内部活动 → 各感觉通道（用"；而且/同时/另外"连接）→ 时间形态。
- 措辞按 `(槽位, seed)` 的哈希从 2–3 个变体里选，**确定性可复现**；开场白也只在多槽位时出现。
- **不能**引入未解码的槽位、修饰或因果；没有合格槽位时不生成句子（弃权仍是合法输出）。
- 没有槽位读出时的行为与从前完全一致（逐通道模板直连），作者示例句保持逐字不变（`tests/test_expression.py` 仍在断言原句）。

## 验收（`scripts/evaluate_renderer.py`，conspecific-v5 测试集 98 窗）

| 指标 | 值 | 含义 |
|---|---|---|
| 渲染窗口 | 98/98 | 每窗都至少有一个合格槽位（果蝇一直看得见光） |
| **不同句子数** | **61** | 固定模板路线在同样窗口里只能产出个位数句子 |
| **虚构槽位** | **0** | 句子里没有解码器没给出的槽位 |
| **无支撑槽位** | **0** | 每个感觉槽位都能对上当窗**实际投递**的通道 |
| **被实测反驳** | **12**（12.2%） | 解码与实测不符（如暗条件下读出"持续"、把"中等活动"读成"活跃"）；**逐条带实测值留档**，不隐藏 |

被反驳的 12 条就是这条通路目前诚实的错误率：它不是"没读出"，而是"读错了"，而且错在哪、实测是什么，都写在 `reports/generative-renderer/conspecific-v5-evaluation.json` 里。

## 与"用语言模型说话"的界线

本层**不含任何语言模型**：措辞来自固定语法，内容来自盲读出。用预训练 LM 生成句子（原构想里的 FLM 路线）是另一回事——LM 的语言能力来自模型而不是果蝇，按项目契约只能作为**单独标注的实验**，不得进入聊天通路。该实验的记录见 `research/flm-experiment.md`。
